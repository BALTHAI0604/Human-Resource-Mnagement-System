# Dayflow - Human Resource Management System

## 📌 Project Overview

Dayflow is a Human Resource Management System (HRMS) developed to simplify and digitize daily HR activities. It provides a centralized platform for managing employee information, attendance, leave, and other HR-related operations.

The system helps organizations reduce manual work, maintain employee records efficiently, and provide an easy-to-use interface for HR administrators and employees.

## 🎯 Objectives

- Manage employee information efficiently
- Maintain centralized employee records
- Track employee attendance
- Manage leave details
- Provide a simple HR dashboard
- Store HR data securely using a database
- Reduce manual HR processes

## 🚀 Features

- Employee Management
- Employee Profile Management
- Attendance Management
